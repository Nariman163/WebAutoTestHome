
## О проекте
Данный проект создан в учебных целях для отработки навыков автоматизации UI-тестирования с использованием Selenium WebDriver и Java. В рамках проекта реализуются автотесты для популярных демо-сайтов:
- [SauceDemo](https://www.saucedemo.com/) — интернет-магазин для тренировки тестирования.
- [the-internet.herokuapp.com](https://the-internet.herokuapp.com/) — набор страниц с типовыми элементами.

Проект находится в активной разработке.
## Стек технологий
- **Java 21** — язык программирования.
- **Selenium WebDriver 4.39.0** — библиотека для управления браузером.
- **JUnit 5** — фреймворк для написания и выполнения тестов.
- **Maven** — система сборки и управления зависимостями.
- **WebDriverManager** — автоматическое управление драйверами браузера.
- **Git** — система контроля версий.
- **Logback (SLF4J)** — планируется для логирования.
- **Allure** — возможно, для отчётов (в перспективе).
